# 01 — 工程骨架：配置 / MySQL / 静态托管 / 管理员登录

**What to build:** 从零起一个可运行的单进程服务：加载外置配置（含敏感项），连上 MySQL，托管前端静态资源，管理员用配置中的单一账号密码登录后台并拿到可用会话。开发者能本地启动、打开管理壳、登录成功。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 进程可启动；缺少必填配置时失败信息明确，密钥不进代码
- [x] MySQL 可连通；基础迁移/建表入口可用（至少支撑会话与后续表扩展）
- [x] 前端构建产物由 Go 托管；浏览器访问得到管理壳页面
- [x] 管理员可用配置中的账号密码登录；错误密码被拒绝
- [x] 登录后具备可校验的管理员会话（Cookie/JWT 等轻量方案均可）；登出后失效
- [x] 未登录访问需鉴权的管理 API 被拒绝
- [x] 健康检查或等价探活可用，便于部署确认
