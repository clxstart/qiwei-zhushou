# 10 — 总账汇总 + 群详情 + 操作/发送日志

**What to build:** 管理员在后台一眼掌控各群账务与流水线：群列表展示群名、状态、定金、总价、尾款、是否已发码、是否结清；群详情含成员快照、流水线步骤状态、账务与最近日志；总账列表可查看与必要维护；汇总今日/本月收入、未结清数量等；操作与发送日志可查清谁在何时入账/发码/结清/反结清/补发。

**Blocked by:** 08 — 结清; 09 — 管理员兜底：代操作 / 反结清 / 补发某步

**Status:** ready-for-agent

- [ ] 群列表展示群名、账务状态、定金、总价、尾款、是否已发码、是否结清
- [ ] 群详情展示成员快照、流水线各步状态、账务字段、最近相关日志
- [ ] 总账视图可浏览记录并支持必要的查看/维护能力（与一群一账模型一致）
- [ ] 汇总至少包含今日收入、本月收入、未结清数量（定义与 settled/入账规则一致且文档化）
- [ ] 日志可筛查 actor、action、群、结果、时间；覆盖入账/发码/结清/反结清/补发
- [ ] 仅管理员可访问上述后台数据
