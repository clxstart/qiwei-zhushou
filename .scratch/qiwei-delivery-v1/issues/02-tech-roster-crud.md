# 02 — 技术花名册 CRUD

**What to build:** 管理员在后台维护技术花名册：每位技术有企微 UserID、姓名、技术栈、工作时间、一句话介绍、群名标识、启用状态。可增删改查；禁用后不再参与建群匹配与抽中。

**Blocked by:** 01 — 工程骨架：配置 / MySQL / 静态托管 / 管理员登录

**Status:** done

- [x] 管理员可创建技术档案并填写上述字段
- [x] 管理员可列表、查看、编辑、删除技术档案
- [x] 禁用某技术后，后续匹配逻辑不会再选中该人（本票至少保证数据层 enabled 可读写；流水线消费在 05）
- [x] 未登录或非管理员无法改花名册
- [x] 关键字段（至少 UserID、姓名）有校验；重复 UserID 行为明确（拒绝或可预期覆盖策略）
