# 03 — 全局配置与收款码素材

**What to build:** 管理员在后台编辑全局运营配置：交付注意事项、业务三段文字（流程/特色/扩展）、群名固定后缀、紧急联系人、消息模板骨架、触发范围开关（默认仅外部客户群 / 可开全部群自测）。可上传并更换全局支付宝收款码图片，供后续发码使用。

**Blocked by:** 01 — 工程骨架：配置 / MySQL / 静态托管 / 管理员登录

**Status:** ready-for-agent

- [ ] 管理员可读到当前全局配置默认值或已存值
- [ ] 管理员可保存注意事项、业务三段、群名后缀、紧急联系人、相关模板字段
- [ ] 触发范围开关可切换并持久化
- [ ] 管理员可上传/更换全局收款码图片；保存后可被后续发码能力引用（本票完成存储与后台可达）
- [ ] 模板支持约定的少量变量占位（如技术名、老板列表、金额、尾款），无需复杂模板引擎
- [ ] 未登录或非管理员无法改配置与素材
