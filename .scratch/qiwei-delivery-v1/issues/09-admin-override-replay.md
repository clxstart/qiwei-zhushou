# 09 — 管理员兜底：代操作 / 反结清 / 补发某步

**What to build:** 管理员在网页后台对任意群代录入账、发尾款码、结清；对已结清群可反结清（写日志）并恢复可发码与可再结清；可对某群补发流水线某一步（只跑该步、遵守幂等，不整单无脑重跑）。保证拉群人不可用时不卡单、失败步骤可修复。

**Blocked by:** 05 — 建群自动流水线 + 账务卡片; 08 — 结清

**Status:** ready-for-agent

- [ ] 管理员可对任意群代操作：入账、发码、结清
- [ ] 管理员可反结清；状态回到可发码/可再结清路径；操作写入日志
- [ ] 反结清后拉群人或管理员可再次发码与结清（在业务规则允许下）
- [ ] 管理员可指定补发流水线某一步；已 done 步骤不重复刷屏；failed/pending 可推进
- [ ] 非管理员无法执行上述兜底操作
- [ ] 单测：管理员结清/反结清恢复；补发不重复已 done 步骤
