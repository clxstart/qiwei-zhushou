# 06 — 群账务：录入定金与总价（卡片/H5）

**What to build:** 拉群人通过账务卡片或手机 H5 录入该群定金与总价；可反复覆盖；系统自动计算尾款=总价-定金。入账成功默认不往群里喊。仅建群者（拉群人）的企微身份操作生效；无权限有明确失败提示。金额非法时有校验错误。账务状态从 `unbooked` 进入 `booked`。

**Blocked by:** 05 — 建群自动流水线 + 账务卡片

**Status:** done

- [x] 拉群人经卡片回调或 H5 企微免登拿到 UserID 后可提交定金与总价
- [x] 仅 creator（拉群人）提交生效；其他人明确失败
- [x] 可反复提交覆盖该群定金/总价；尾款自动重算
- [x] 校验：总价>0、定金≥0、定金≤总价（或与共识等价的明确规则）；非法输入返回可读错误
- [x] 入账成功默认不向客户群发送通知
- [x] 状态进入 `booked`（或等价「已入账待发码」）
- [x] 单测：入账 3000/8000 → 尾款 5000；再入账 2000/8000 → 定金覆盖为 2000
