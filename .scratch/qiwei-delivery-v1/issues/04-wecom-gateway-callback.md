# 04 — WeComGateway + 企微回调验签解密

**What to build:** 企微协议层可独立工作：对外暴露回调入口完成 URL 验证与加密消息解密；通过 `WeComGateway` 抽象发送文本/图片、改群名等（真实现可连企微，测试用假实现记录调用）。本层不含建群业务规则，只提供干净的协议能力给后续 `DeliveryBot` 使用。

**Blocked by:** 01 — 工程骨架：配置 / MySQL / 静态托管 / 管理员登录

**Status:** ready-for-agent

- [ ] 企微回调 URL 验证（echostr）在配置正确时可成功响应
- [ ] 加密回调可验签并解密得到明文事件载荷
- [ ] `WeComGateway` 接口覆盖 V1 所需：发文本、发图片、改群名，以及后续流水线/账务所需的最小能力集合
- [ ] 假 `WeComGateway` 可注入，并记录调用序列（类型、目标群、关键参数摘要）
- [ ] 协议层不实现角色匹配、账务状态机等业务规则
- [ ] 错误与重试边界有日志；失败以 error 返回，不吞错
